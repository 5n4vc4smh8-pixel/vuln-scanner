# Política de Segurança

## Reportando uma vulnerabilidade

Segurança é a razão de existir deste projeto. Se você encontrar uma vulnerabilidade no `vuln-scanner`, queremos saber o mais rápido possível.

**Por favor, não abra uma issue pública** para vulnerabilidades de segurança — isso exporia usuários a ataques antes de uma correção estar disponível.

### Processo de reporte

1. Envie um e-mail para **[seu-email@dominio.com]** com o assunto `[SECURITY] vuln-scanner`.
2. Descreva a vulnerabilidade, os passos para reproduzi-la e a versão afetada.
3. Aguarde a confirmação de recebimento (até 3 dias úteis).
4. Trabalharemos juntos para validar e corrigir o problema.

### O que você pode esperar

| Etapa | Prazo |
|-------|-------|
| Confirmação de recebimento | até 3 dias úteis |
| Avaliação inicial | até 7 dias úteis |
| Correção e divulgação responsável | até 30 dias |

Divulgaremos a correção em um release com créditos ao pesquisador, salvo pedido de anonimato.

## Uso responsável

Este software deve ser usado apenas em sistemas próprios ou com autorização explícita do proprietário. Scan não autorizado é ilegal na maioria das jurisdições.
